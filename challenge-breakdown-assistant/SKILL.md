# 挑战任务拆解助手

## 什么时候用

拿到一份看不懂的挑战任务（课程挑战、竞赛题、项目 brief），不知道它要我做什么、哪些步骤必须自己做、做到什么程度算完成。

## 输入

- 挑战任务原文（正文 / 评分规则 / 交付物清单）

## 输出（四项，缺一不可）

1. **人话翻译**（≤3 句）：这题要我做什么、想教我什么、完成标志是什么
2. **判断点**：哪些决定必须"本人"拍板（判断 / 取舍 / 验收 / 复盘），AI 只给候选
3. **验收标准**：每个交付物"怎样算完成"的可检查标准
4. **开工清单**：按顺序列出动作，标清每步是"我"还是"AI"

## 使用步骤

1. 把挑战原文 + 评分规则发给 AI，附一句："用『挑战任务拆解助手』帮我拆"
2. 让 AI 按上面四项输出
3. 重点看「判断点」——这些是你必须自己拍板的决定
4. 按「开工清单」逐项推进，每项对照「验收标准」检查
5. 做完后，把「判断点里你实际做的决定」写进复盘

## 三条铁律

- **先翻译再动手**：没看懂就开干，等于在错误方向上花钱花时间
- **关键数字回源头验证**：AI 会记错数字，关键数值必须回到官方材料核实
- **判断点不让渡**：AI 是"考生/动手人"，你是"判卷人/决策人"，取舍和验收永远你拍板

## 真实案例（C2G 参数高尔夫）

- 挑战原文：在 $25 / 16MB / 10min 约束下，复现并优化一个极小语言模型
- 人话翻译：不是要我变算法工程师，是练"在陌生领域指挥 AI 做判断"
- 判断点：走"过程分路线"还是"打榜满分"——AI 只给分析，我拍板
- 验收标准：四件套交付物 + 仓库 + 一份诚实分数记录
- 关键数字回源验证：AI 曾把 SP1024 说成 SP4096，回官方 tokenizer_specs.json 核实后纠正
