# 宋俊毅 C4 技能说明 —— 挑战任务拆解助手

> 一句话：**把看不懂的挑战任务，拆成"人话翻译 + 判断点 + 验收标准 + 开工清单"**，让不写代码的人也能指挥 AI 独立完成陌生挑战。

---

## 一、它解决什么问题

在 Elite20 这类课程里，很多挑战对不写代码的同学是"天书"：不知道任务到底要我做什么、哪些步骤必须自己做、做到什么程度算完成。结果要么卡住不敢动，要么"一句话让 AI 直接交"——这两种都学不到东西。

这个技能把"拆解陌生任务"这件我反复在做的事，固化成一份可以复制的工作流：

- 拿到一份挑战 → 先翻译成人话
- 分清哪些是 AI 干的活、哪些决定必须我拍板
- 每个交付物给一条能检查的验收标准
- 列一张按顺序走的开工清单

## 二、适用场景

- 课程挑战 / 竞赛题 / 公司项目 brief，第一次看到"看不懂"
- 想确认"哪些步骤必须本人做、哪些能交给 AI"
- 想避免"一句话指令直接交作业"的低质量交付

## 三、输入 / 输出

| | 内容 |
|---|---|
| **输入** | 挑战任务原文（正文 + 评分规则 rubric + 交付物清单） |
| **输出** | ① 人话翻译（≤3 句）② 判断点（必须本人拍板的决定）③ 验收标准（每件交付物"怎样算完成"）④ 开工清单（每步标"我"还是"AI"） |

## 四、使用步骤

1. 把挑战原文 + 评分规则发给 AI，附一句："用『挑战任务拆解助手』帮我拆"
2. 让 AI 按上面四项输出
3. 重点看「判断点」——这些是你必须自己拍板的决定
4. 按「开工清单」逐项推进，每项对照「验收标准」检查
5. 做完后，把「判断点里你实际做的决定」写进复盘

## 五、真实案例（我在 C2G 上的实践）

- **挑战原文**：在 $25 / 16MB / 10min 约束下，复现并优化一个极小语言模型
- **人话翻译**：不是要我变成算法工程师，而是练"在陌生领域指挥 AI 做判断"
- **判断点**：走"过程分路线"还是"打榜满分"——AI 只给分析，最终我拍板
- **验收标准**：四件套交付物 + 仓库 + 一份诚实分数记录
- **回源验证**：AI 曾把基线词表 SP1024 说成 SP4096，我回到官方 tokenizer_specs.json 核实后纠正——这就是"判断点不让渡"的实际意义

## 六、为什么这算一个"技能"

它满足 C4 的四个条件：

- **可复用**：任何不写代码、要独立完成挑战的人都能套用，不依赖我的环境
- **可执行**：核心是 SKILL.md 里的一段工作流 prompt，丢给任意 AI 就能跑
- **可验证**：给定同一份挑战原文，能稳定产出四项拆解结果
- **IO 明确**：输入=挑战原文/评分规则，输出=人话翻译+判断点+验收标准+开工清单
