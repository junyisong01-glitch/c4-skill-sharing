# 挑战任务拆解助手（challenge-breakdown-assistant）

把「看不懂的挑战任务」拆成 **人话翻译 + 判断点 + 验收标准 + 开工清单** 的可复用 AI 技能。

> 一句话：不写代码的人，也能靠指挥 AI 独立完成一道陌生挑战。

## 它解决什么问题

很多课程挑战 / 竞赛题 / 项目 brief，对第一次看到的人就是「天书」：

- 不知道任务到底要我做什么
- 不知道哪些步骤必须自己做、哪些能交给 AI
- 不知道做到什么程度才算完成

结果要么卡住不敢动，要么「一句话让 AI 直接交」——两种都学不到东西。

这个技能把「拆解陌生任务」固化成一段可复制的工作流 prompt，丢给任意 AI 就能用。

## 快速开始

1. 打开本仓库里的 `challenge-breakdown-assistant/SKILL.md`
2. 把这段内容作为「系统提示 / 技能」，粘贴给任意 AI（ChatGPT、Claude、Gemini、豆包等）
3. 再把你的挑战原文 + 评分规则发给它，附一句：

   > 用「挑战任务拆解助手」帮我拆

4. AI 会输出四项：人话翻译、判断点、验收标准、开工清单

## 输出四项（缺一不可）

| 项 | 含义 |
|---|---|
| 人话翻译 | 这题要我做什么、想教我什么、完成标志是什么（≤3 句） |
| 判断点 | 哪些决定必须「本人」拍板（判断 / 取舍 / 验收 / 复盘），AI 只给候选 |
| 验收标准 | 每个交付物「怎样算完成」的可检查标准 |
| 开工清单 | 按顺序列出动作，每步标「我」还是「AI」 |

## 三条铁律

- **先翻译再动手**：没看懂就开干，等于在错误方向上花钱花时间
- **关键数字回源头验证**：AI 会记错数字，关键数值必须回到官方材料核实
- **判断点不让渡**：AI 是「考生 / 动手人」，你是「判卷人 / 决策人」，取舍和验收永远你拍板

## 真实案例

在 **OpenAI Parameter Golf（C2G）** 挑战上的实践——在 $25 / 16MB / 10min 约束下复现并优化极小语言模型：

- **人话翻译**：不是要变成算法工程师，是练「在陌生领域指挥 AI 做判断」
- **判断点**：走「过程分路线」还是「打榜满分」——AI 只给分析，我拍板
- **验收标准**：四件套交付物 + 仓库 + 一份诚实分数记录
- **回源验证**：AI 曾把基线词表 SP1024 说成 SP4096，回官方 tokenizer_specs.json 核实后纠正
